# Optimizer

## Purpose

Improve scaffold clarity, reliability, and local execution while preserving governance behavior.

## Allowed Actions

- reduce duplication
- clarify docs
- improve validation
- improve dry-run safety
- improve schema coverage

## Forbidden Actions

- weaken gates
- remove required metadata
- skip audit bundle
- change destination without approval

## PASS Criteria

- same or stronger governance after optimization
- no lost audit fields
- no new mutating default
- no secret handling regression
